Quick Start

Install on Any Linux Distribution

Choose your distribution below for fast, automated setup.

Recommended Automatic Updates via APT Ubuntu 26.04, 24.04 & 22.04 LTS

The official Launchpad PPA provides packages built natively in Canonical's cloud builders for Ubuntu, Linux Mint, and Pop!_OS. System dependencies are resolved automatically, and updates arrive seamlessly via sudo apt upgrade.

1
Add the official Launchpad PPA repository: 
sudo add-apt-repository ppa:danielcook2016/linux-jagex-launcher
2
Install Linux Jagex Launcher: 
sudo apt update && sudo apt install -y linux-jagex-launcher
3
Launch from your application menu or terminal: 
linux-jagex-launcher
Prefer direct .deb download, automated script, or Ubuntu 26.04 APT cleanup?

One-line automated installer (fetches v1.5.1, removes broken legacy Jagex trusty APT entries if present, and installs cleanly):

curl -sSL https://launcher.patchcraft.dev/install.sh | bash

Or download the standalone .deb package manually:

curl -LO https://github.com/cook0001/Linux-Jagex-Launcher/releases/latest/download/jagex-launcher_1.5.1_amd64.deb && sudo apt install ./jagex-launcher_1.5.1_amd64.deb

Seeing NO_PUBKEY 7373B12CE03BEB4B or trusty InRelease is not signed on Ubuntu 24.04 / 26.04 ("Resolute Raccoon")? Remove Jagex's deprecated Ubuntu 14.04 repository left over from Jagex's old website instructions:

sudo rm -f /etc/apt/sources.list.d/runescape.list /etc/apt/sources.list.d/runescape.sources && sudo apt update
Fedora Copr Automatic Updates via DNF Fedora 40+ & RHEL / Nobara / Bazzite

The official Fedora Copr repository provides packages built natively in Fedora's build infrastructure. Updates are delivered automatically via sudo dnf upgrade, or you can install the standalone .rpm directly.

1
Enable the official Fedora Copr repository: 
sudo dnf copr enable -y cook0001/linux-jagex-launcher
2
Install the launcher package: 
sudo dnf install -y linux-jagex-launcher
3
Launch from your application menu or terminal: 
linux-jagex-launcher
Prefer direct standalone .rpm installation?

Download and install the standalone .rpm package directly with DNF:

curl -LO https://github.com/cook0001/Linux-Jagex-Launcher/releases/latest/download/linux-jagex-launcher-1.5.1.x86_64.rpm && sudo dnf install -y ./linux-jagex-launcher-1.5.1.x86_64.rpm
Standalone Pacman & AUR Arch Linux, Manjaro & EndeavourOS Direct Offline or AUR Install

Install via standalone native .pacman binary package for instant setup, through an AUR helper, or with the local makepkg script:

1
Standalone Pacman Binary Package (fastest direct install): 
curl -LO https://github.com/cook0001/Linux-Jagex-Launcher/releases/latest/download/linux-jagex-launcher-1.5.1.x64.pacman && sudo pacman -U ./linux-jagex-launcher-1.5.1.x64.pacman

Using yay (AUR helper): 
yay -S linux-jagex-launcher-bin
3
Using paru (Rust AUR helper): 
paru -S linux-jagex-launcher-bin
4
Manual makepkg install from AUR: 
git clone https://aur.archlinux.org/linux-jagex-launcher-bin.git && cd linux-jagex-launcher-bin && makepkg -si

Common Inquiries

Frequently Asked Questions

Answers regarding game security, anti-cheat, account migration, Ubuntu 26.04 compatibility, and performance tuning.

Will I get banned for using Linux Jagex Launcher?

No. This launcher does not modify game code, alter memory, intercept network packets, or inject unauthorized hooks into game clients. It utilizes official Jagex OAuth 2.0 PKCE authentication and hands your authenticated session directly to official, verified game binaries (RuneLite, HDOS, or native RuneScape 3).

How does RuneLite work? Do I lose my plugins or settings?

Your plugins, tile markers, bank tags, and configurations remain 100% untouched. The launcher launches RuneLite within your standard user home directory, preserving ~/.runelite while enabling in-game web links to open in your default Linux browser.

Can I play on Linux if I have migrated to a Jagex Account?

Yes! Migrated Jagex Accounts can no longer use legacy login screens. Linux Jagex Launcher executes the official OAuth 2.0 PKCE flow, handles Cloudflare Turnstile verification natively, and securely passes your active session into your selected game or client.

How does the native Linux RS3 client run without root?

The launcher unpacks Jagex's official Linux package into local userspace storage, allowing it to install and update without ever requesting sudo or root privileges.

Why does RuneScape 3 freeze on "Loading application resources" and how do I fix it?

This freeze is typically caused by Wayland compositor conflicts with the legacy client or audio buffer underruns. Linux Jagex Launcher resolves this automatically by applying display server, input method, and audio latency compatibility fixes on launch, plus an optional Vulkan-backed OpenGL compatibility override in Settings.

How do I fix "NO_PUBKEY 7373B12CE03BEB4B" or "trusty InRelease is not signed" on Ubuntu 24.04 & 26.04?

Jagex's website still instructs Ubuntu users to add their deprecated Ubuntu 14.04 (trusty) APT repository (https://content.runescape.com/downloads/ubuntu) via sudo apt-key add -. On Ubuntu 24.04 LTS and Ubuntu 26.04 LTS ("Resolute Raccoon"), apt-key has been removed and APT 3.x strictly rejects unsigned / legacy SHA-1-signed repositories, causing sudo apt update to fail. Linux Jagex Launcher never uses that repository because it manages the native RS3 client rootlessly in userspace. Remove the leftover repository file with sudo rm -f /etc/apt/sources.list.d/runescape.list /etc/apt/sources.list.d/runescape.sources && sudo apt update (or click Remove Legacy Repo inside Settings → Run Diagnostics).

How does the launcher resolve libssl1.1 on Ubuntu 22.04, 24.04, and 26.04?

Modern Ubuntu releases dropped libssl1.1. The native RS3 NXT client was linked against OpenSSL 1.1 and crashes on clean installations. Rather than risking your package manager with old third-party packages, Linux Jagex Launcher provisions isolated userspace OpenSSL 1.1 compatibility libraries scoped exclusively to the game process, keeping your system 100% clean.

Does it support Feral GameMode and MangoHud?

Yes! Both Feral GameMode (gamemoderun) and MangoHud can be toggled on/off in the Launcher Settings modal for high-performance CPU governor scheduling and real-time performance overlays.
